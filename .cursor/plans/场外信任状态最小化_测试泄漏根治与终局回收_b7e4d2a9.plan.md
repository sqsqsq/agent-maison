## 设计原则（此后红线）

**场外数据 = 活跃/可恢复 run 的临时恢复区，不是历史档案库。** per-run 状态只在活跃/
可恢复期存在，成功封卷或明确放弃即删除；普通完整性靠仓内签名/hash 做"检测并停止"；
**新增场外状态类型须先证明「in-repo 产物 + 签名/哈希绑定」做不到，默认不允许**。

## Todo 2：生命周期回收（封卷 + 事件点删除 + 红线落笔）

**封卷**：最新 authoritative `run_end.status ∈ {CHAIN_SLICE_COMPLETED, legacy COMPLETED}`
⇒ sealed——**任何解析到该 run_id/report_dir 的启动一律拒绝**（不只 `--resume`：
现有 `--manifest` 可加载既有 run 的 manifest 且后续覆写 manifest.json，只判
argv.resume 的 guard 会被 `--manifest` 重新打开）；`--force` / `--force-resume` 均不可
绕过；独立分支，不并入 TERMINAL_STATUSES 的 cooldown/blocking-cleared 体系。检查在
取得 feature lock 后、`loadAuthoritativeEvents` 之后立即执行，先于一切 trust-state
读取（含 manifest drift 的 checkpoint meta 读）、manifest/config 写入、canary/preflight。
**sealed 拒绝只输出错误，不追加任何事件**（resume_rejected 等都不写）——封卷后其归档
不再被修改。**锁生命周期钉死**：现状 `acquireGoalLocks`（:3408）与保护性 `try {`
（:3449）之间是裸区——sealed 分支在此提前 return 会遗留锁（finally 的 releaseAllLocks
只盖 try 内；process.on('exit') 只算后备）。实现=**把既有 try 前移**到紧跟
acquireGoalLocks，`loadAuthoritativeEvents → sealed guard → manifest drift → 主流程`
全部入 try、finally releaseAllLocks——不加新锁机制。报错文案引导新开 run。
COMPLETED 仅 legacy 读取兼容（新代码不得写出，phase-transition-policy.ts:43）。

**回收决策表**：

| 事件/状态 | 该 run 的场外状态 |
|---|---|
| 成功封卷（CHAIN_SLICE_COMPLETED，全部收尾完成） | 删除（见删除点） |
| `--supersede` / 明确放弃 | 删除被替代 run |
| HALTED / PARTIAL / INTERRUPTED / AWAITING_HUMAN_REVIEW / DEFERRED* / 活跃 | 保留 |
| 状态无法证明 | 不自动删，console 诊断一行 |

**实现钉死**：删除点=全部终局收尾结束（completion receipt / finalize_overrun /
progress 终刷 / `runConcluded=true`）后、持 feature lock、return 前 best-effort（失败仅
记录）；逻辑删除单元=同 runId 的 flat checkpoint（`<runId>.json`）+ run 目录一起删
（允许部分成功、逐路径诊断；不动 vision-heads/HWM）；runId 严格路径契约（合法单
basename、等于已验证 manifest 的 run_id、resolve 后位于预期根下、逐级非 symlink，
失败只诊断不删）；**supersede 两条追加**：① `target_run_id !== manifest.run_id`，
否则 BLOCKER（运行中删自己的 checkpoint/pass snapshot 是新删除能力带来的新风险）；
② 先验证目标 manifest 身份、**成功追加 supersede 审计事件之后**才 best-effort 删除
目标场外状态——事件追加失败绝不删除（不建新事务/删除账本）；dry-run 零接触；
零新增机制。

**红线落笔（本项收尾）**：设计原则注释加在 `pass-snapshot.ts` 头部与 `goal-runner.ts`
`visionTrustDir()` 两入口 + AGENTS.md 一句开发约束。不抽 path helper。
