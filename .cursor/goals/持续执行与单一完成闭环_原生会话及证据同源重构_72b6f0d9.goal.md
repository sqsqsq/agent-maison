> 架构对齐：[architecture.md](../../docs/architecture.md) §1、§2、§4、§6、§8；I1–I10。

## 2. 目标执行模型

> 架构对齐：[architecture.md](../../docs/architecture.md) §2、§3；I1、I3、I4、I6、I9、I10。

一个原请求保留现有 root 身份；初建设计及其后续共享设计修订使用该设计单元的专用作者会话，每个 CU 施工使用各自专用作者会话。工作单元是既有 root/CU run 的职责视图，不新增第四种业务对象或跨单元运行中心。单职责请求、普通维护使用同一内核、单个适用工作单元，不强造蓝图/CU或六阶段。

有人在场与无人值守都把工作交给专用执行会话，主 Agent 只转交用户目标、授权和插话，呈现真实进度。它提前结束会话不能结束工作单元。执行会话可退出再按准确 ID 接续；不能原生接续时，框架从原需求、当前成果、有效检查和未完事项重建**新的专用会话**，不能退回主 Agent 手工施工。原生能力缺失与不能运行任何专用执行者是两件事：后者如实记能力缺口，不能声称支持。

同一单元作者可以完成授权内的设计细化、实现和测试编写，不再按 spec/plan/coding/ut 身份轮流限制写入。阶段名可保留作 Skill 名、检查族、证据分类及人读里程碑，不能再当派工队列、硬前置或收口许可。正式需求仍先进部件设计；CU 的边界和验收来自已准入蓝图；改变共享设计、公共契约或扩大单元范围时，把问题送回设计单元正式修订、独立质询、发布和重绑。受影响工作等结果，其它合法工作继续；施工会话不得原地自授新范围。

执行闭环只有一条：**准备当前事实 → 同一专用作者会话解题/调用工具 → 收集机器检查与独立核验 → 统一处置当前未完项 → 继续、等待条件、暂停或正式完成**。模型说完成、进程退出、原生 Goal/Stop hook 放行都是“请求检查完成”的信号，不是完成证明。现有 `GoalPhaseRuntime` 原位收缩为该协调器，不在外面再套业务循环。

### 2.1 真实边界与测试独立性

> 架构对齐：[architecture.md](../../docs/architecture.md) §3.1、§4；I1、I4、I9。

原需求/验收来源、跨单元共享设计、framework 发布件、秘密和不可逆动作仍受真实授权保护。作者可以起草测试、调整测试以匹配已批准规格；**验收到测试的对应关系与断言强度由独立核验判断**，不得以作者自评替代。既有 c2 的有限兼容修补规则中有价值的断言防削弱证据保留为核验输入，不再用阶段身份禁止同一作者编写新测试。

构建、UT、真机和视觉验证通过框架工具执行，结果由执行器/独立 verifier 产生并由框架落盘。testing 的正式截图、原始日志、测试结果、验证报告、闭环和完成记录继续写保护；作者只写测试输入/源码和明确的反馈入口，不能手填 PASS。机器检查防明显破坏，独立核验防“测试都绿但试卷被改弱”；两者不能互相取代。能力缺口保留未知，只挡依赖它的工作及适用完成，不把未知当产品失败，也不当通过。

### 2.2 配额退出与收敛

> 架构对齐：[architecture.md](../../docs/architecture.md) §4、§5；I2、I5、I7、I10。

删除 Maison 的 token/调用次数/默认总墙钟配额、预算提额、跨 run 预算累加控制和本地内容重试次数终止。新请求不生成这些上限；旧字段只作历史显示。用户明确说的时限、取消和工具卡死超时保留；有活性的长作者会话不得被旧 phase timeout 当作总预算掐断。额度、认证、服务错误按实际环境故障保全后可续，不查询账户剩余、不预测可用量、不自动换模型/凭据绕过限制。

循环停止出口仅为：目标达成；用户时限/取消；真实授权边界；依赖无法满足且需要人或框架处理的环境/执行故障；可续的无进展暂停。产品缺陷交回作者，机器账本自己重建，无关工作继续。暂停须说明剩余验收、阻碍、可继续条件；有真实可检测条件才自动唤醒，无变化不盲拉。

无进展比较**完成定义下的未满足验收及已核实发现**，不能只看文件是否变了。在可比较的完成评估中，持续没有证据证明更接近完成、或相同问题往复出现才暂停；新证据证实子问题解决算进展，改编号/时间/文案不算。不是按调用数到点停止，也不能仅因总问题数暂时增加就停；新发现可能是有效验证。会话运行中的检查结果与相关产物变化同样进入这一比较，不等作者退出；判定无进展时协调器经现有运输中断该会话，保全成果后可续暂停。有证据进展则继续；只有检查未完成或缺可比较依据时才补观察，不把 unknown 伪装无进展。P2 定义唯一比较，现有 `shouldHaltNoProgress` 原位改造，不另建评分/计数账本。
