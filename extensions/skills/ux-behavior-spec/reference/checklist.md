# 行为核对清单

按请求范围选用适用项。每个给定、操作和结果都应能回查来源。

- 数据改变时，验证显示、可选值和数量。动态列表检查同一个行模板在仅有一项和有多项的数据下的表现。
- 区分单选、多选、同意条款和信息文案。检查有效选中状态、按钮触发条件、可点击范围和空态。
- 核对直接跨页动作、目的、携带的业务数据及成功和失败出口。分别核对进入目的页的当下是否关闭源浮层、从目的页返回的去向、返回后是否保留选择，适用时也核对重新进入。缺产品依据的事项分别保持待决，关联到对应元素。
- 表单按需检查键盘、输入约束、提交状态和时间边界。展示掩码和业务携带的原值分别表达。
- 对照截图、PRD 条款、结构化节点或产品决定，核实每项断言的来源。图中状态与产品默认值分别核对。
