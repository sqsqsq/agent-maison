## Scope

只修现行棘轮规范与既有终态完成契约的文字冲突。样本是否完成调用共享纯判据；棘轮继续只读既有事件，事件 `exit_code` 仅适配为函数输入 `exitCode`。

## Compatibility

旧 exit0 且无否定事实的事件继续识别；旧 exit1 缺完成观测不追认成功。会话 passed 沿既有报告转换给出 exit0，waiting 不获得完成资格。辅助调用的展示阶段不改变棘轮样本归属。倍率、上限、预算、授权和恢复路由不变，不新增状态、字段、协议或门禁。

## Validation

复用计划中的共享真值表、实际运输结束事件、棘轮重建及 resume 反例。集中执行 `cd harness && npm test`；修改规范后执行 `npm run openspec:validate`。本次明确禁止打包，因此不执行会隐式 pack 的 `npm run release:verify`，该发布检查留给后续获授权的发布任务。
