# Design

`readCurrentDispositionInput` assembles complete current facts; `resolveCurrentDisposition` remains the pure action resolver and existing responsibility resolution selects the legal owner. Related frozen acceptance execution, assertions and bound sources are selected by the same material path used by the original verifier. When an old finding has not covered that evidence, the existing verification-required representation takes precedence over author repair.

Writers, runtime prompts, diagnosis, closure and public next steps consume that complete action. Raw verifier PASS/FAIL continues to use its existing severity contract; it cannot independently declare current work finished. The shared Skill guidance and generated verifier role explain this distinction.

A settled author may be reused when its corresponding gate report/event window proves raw PASS and any outer failure is only the current old finding awaiting verification. Real gate failure, unknown negative source, expired binding or changed business input retains normal repair/revalidation. Reuse does not depend on retry ordinal. Pure gate/verification/transcription does not consume content-repair allowance; model calls and wall clock retain their original accounting. Reaching the total limit prevents a new call, while already-authorized machine-only finalization can finish within wall time.

History is immutable. S2 is a captured delta over the retained S1 input set, with original byte hashes and explicit overwritten-file gaps. Replay adapters must state environment changes and may not research facts, remove findings, change owners or manufacture completion to make the scenario pass.
