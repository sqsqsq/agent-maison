## ADDED Requirements

### Requirement: Deterministic preparation preserves business decisions

Preparation SHALL derive stable technical identifiers, known containers, discovery sources, admission projections and scope parameters from existing schema and authority. It MUST aggregate independently decidable design/CU projection issues without a constructable-only or first-error blind spot. Unknown applicability, business contradictions and independent questioning answers MUST NOT be filled by machine assumptions. Existing writers remain sole publication paths.

#### Scenario: An independent projection issue exists with a design gap
- **WHEN** both issues can be determined from current inputs
- **THEN** one preparation/check result reports both while dependent unknowns explain the missing input

### Requirement: Independent revision review uses public evidence and actual changes

Independent questioning/verifier input SHALL include the previous public report and unresolved findings, actual changes, affected dependencies and current effective evidence. Unaffected conclusions may be retained; changed material MUST NOT be automatically accepted by a historical PASS. The existing P1 questioning result writer SHALL preserve substantive answers and machine-maintained identity envelopes.

#### Scenario: Only two references change
- **WHEN** the original independent report and trustworthy change evidence are available
- **THEN** only affected conclusions require new verification and unrelated valid evidence is reused

#### Scenario: Questioning output has a format error
- **WHEN** the business design has not changed
- **THEN** only the independent output format is repaired through the existing receipt path without rewriting business content or changing a negative answer
